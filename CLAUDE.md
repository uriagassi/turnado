## Working rules

- This repo is public. Never put details about the owner's own infrastructure in commits, PR titles or bodies, or issue/PR comments: real hostnames, IPs, ports, admin URLs, email addresses, credentials, or which third-party providers they use (mail, DNS, hosting), even well-known ones. Describe the bug generically (file paths, config key names, "the SMTP host"). When in doubt, ask before pushing.
- Keep inline code comments to a one-liner at most. Put the rationale and history in the commit message or the ticket.
