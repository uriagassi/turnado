# turnado

## Agent skills

### Issue tracker

Issues live as GitHub Issues on `github.com/uriagassi/turnado`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary, used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root (not yet created — this repo is pre-build). See `docs/agents/domain.md`.
